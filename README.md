# sh0tybumbati.github.io

Portfolio home page. `index.html` + `style.css` + `script.js`, no build step.

- The wall and workbench are hand-edited in `index.html` (most game repos are private).
- `notes/` holds devlog pages.
- The archive section is pulled live from the GitHub API; hide a repo by adding it to `EXCLUDED` in `script.js`.
